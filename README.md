# CW32 万用表：电压、电流测量与按键标定

基于 **CW32F030C8** 的嵌入式电压、电流表项目，包含 Keil 固件源码和 Altium 原理图、PCB 设计文件。通过双通道 ADC 采集电压与电流，使用上下两排三位数码管显示，并支持按键两点标定及 Flash 参数保存，适合学习单片机采样、数字滤波、动态显示和参数持久化。

当前实现的是电压、电流测量功能，尚未实现电阻、通断或交流有效值测量。

## 主要功能

- **双通道采样**：PB10 / IN11 采集电压，PB11 / IN12 采集电流。
- **数字滤波**：每路保存 20 个采样值，去掉一个最大值和一个最小值后求平均。
- **数码管显示**：上排显示电压，下排显示电流；每 1 ms 扫描一位，每 300 ms 更新测量读数。
- **按键标定**：电压标定点为 5 V、15 V，电流标定点为 0.5 A、1.5 A；分别修正斜率和偏移。
- **断电保存**：采用两页 Flash 交替存储和记录校验，上电加载有效标定参数。
- **错误提示**：支持采样未就绪、标定点无效、Flash 保存失败的显示提示。

## 硬件配置

| 项目 | 配置 |
| --- | --- |
| 主控 | CW32F030C8，工程时钟 64 MHz |
| ADC | 12 位，内部 1.5 V 参考，电压/电流连续序列采样 |
| 电压采样 | 220 kΩ 与 10 kΩ 分压，理论分压比 23 |
| 电流采样 | 100 mΩ（0.1 Ω）采样电阻，当前换算未包含额外放大器 |
| 显示 | 两排三位共阴数码管，段选高电平有效、位选低电平有效 |
| K1 / PB12 | 切换正常显示及四个标定模式 |
| K2 / PB13 | 保存当前标定点，成功后回到正常显示 |
| K3 / PB14 | 退出标定，不保存当前输入 |

按键接地触发，使用输入上拉和软件消抖。显示格式在小于 10 时为 `x.xx`，10 及以上为 `xx.x`；显示范围不代表硬件允许的输入范围，实际量程取决于电路、器件额定值和实测结果。

## 打开工程

### 固件

1. 安装 Keil µVision 5、ARM Compiler 5 和 CW32F030 所需的设备支持包。
2. 打开仓库根目录的 `工程模板.uvprojx`。
3. 执行 **Rebuild**，确认编译成功后，根据实际调试器配置下载参数。

项目最近一次固件验证使用 ARMCC 5.06 update 5，编译结果为 0 errors、0 warnings。部分 C/H 文件采用 GBK 编码，编辑时请保留编码，避免中文注释乱码；仓库通过 `.gitattributes` 保留原文件字节和换行。

### 硬件

使用 Altium Designer 打开：

`Hardware/Altium_万用表_2026-10-29/万用表/Board1.PrjPcb`

工程内包含 `Board1/Schematic1/P1.schdoc` 原理图和 `Board1/PCB1.pcbdoc` PCB 文件，也可以下载原始 ZIP 后解压打开。

## 标定与参数保存

使用外部参考仪表确认输入依次为 **5.00 V、15.00 V、0.50 A、1.50 A**，按 K1 进入对应模式，待输入稳定后按 K2 保存。每个通道只有两个标定点都有效时才启用拟合，否则继续使用理论换算。

参数保存在 Flash 的 `0xFC00–0xFFFF`，工程代码区已为此预留最后 1 KB。正常断电可保留参数，下载器执行全片擦除会清除参数，需要重新标定。完整操作见[标定操作说明](标定操作说明.md)。
